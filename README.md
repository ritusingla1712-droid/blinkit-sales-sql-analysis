# 🛒 Blinkit Sales Data Analysis using SQL

## 📌 Problem Statement

Analyze Blinkit's grocery sales dataset to understand product performance, pricing trends, and sales distribution across different outlet types, locations, and item categories.

---

## 📂 Dataset Description

The dataset contains detailed information about grocery products sold through Blinkit outlets, including:

* Item Identifier
* Item Type
* Item Fat Content
* Item Weight
* Item MRP
* Outlet Size, Type, and Location
* Outlet Establishment Year
* Item Outlet Sales

---

## 🛠 SQL Concepts Used

This project demonstrates strong SQL fundamentals, including:

* SELECT, WHERE, DISTINCT
* Aggregate Functions (SUM, AVG, COUNT, MAX, MIN)
* GROUP BY & ORDER BY
* Filtering using conditions
* Subqueries
* Data exploration and analysis

---

## 🔍 Key Analysis Performed

### 📊 Data Exploration

* Identified unique item types and fat content categories
* Counted total number of products
* Checked distribution of outlet sizes and locations

### 💰 Pricing Analysis

* Found maximum, minimum, and average Item MRP
* Analyzed price distribution across item categories
* Compared pricing trends by outlet type

### 📦 Product Insights

* Count of items by category
* Sales contribution by item type
* Performance of Low Fat vs Regular items

### 🏪 Outlet Analysis

* Sales performance by outlet size and type
* Impact of outlet location (Tier 1, Tier 2, Tier 3)
* Trends based on establishment year

### 📈 Sales Analysis

* Total sales by item type
* Sales filtered by location and fat content
* Highest and lowest performing categories

---

## 💡 Key Insights

* Certain product categories contribute significantly to total sales
* Outlet type and location heavily impact sales performance
* Low Fat and Regular products show different sales behavior
* Pricing does not always directly correlate with higher sales
